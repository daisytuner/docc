The C++ API reference is generated with [Doxygen](https://www.doxygen.nl/) from the headers of all docc modules.

**[Open the C++ API reference →](cpp-api:index.html)**

## Covered modules

| Module           | Headers                  |
| ---------------- | ------------------------ |
| `sdfg`           | `sdfg/include`           |
| `opt`            | `opt/include`            |
| `llvm`           | `llvm/include`           |
| `mlir`           | `mlir/include`           |
| `c-compile`      | `c-compile/include`      |
| `rpc`            | `rpc/include`            |
| `rtl`            | `rtl/include`            |
| `arg-capture-io` | `arg-capture-io/include` |
| `targets`        | `targets/et/include`     |

The Python and PyTorch components expose no C++ headers.

## Building locally

The reference is built by [daisytuner/docs-platform](https://github.com/daisytuner/docs-platform) from the `main` branch. To preview it with your local checkout, see that repository's README.
