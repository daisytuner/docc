# docc documentation site

Source of [docc.daisytuner.com](https://docc.daisytuner.com): a [Docusaurus](https://docusaurus.io/) site with the C++ API reference generated by [Doxygen](https://www.doxygen.nl/).

| Path | Contents |
| ---- | -------- |
| `docs/` | Guides (Markdown) |
| `docs/generated/` | Pages copied from elsewhere in the repo by `scripts/sync-repo-docs.mjs` (not checked in) |
| `doxygen/` | Doxyfile, API main page, vendored doxygen-awesome-css theme |
| `static/api/` | Doxygen output (not checked in) |
| `src/pages/` | Landing page |

## Prerequisites

- Node.js 24 and npm
- `doxygen` and `graphviz` (only for the C++ API reference)

## Develop

```bash
cd docs-site
npm ci
npm start            # dev server at http://localhost:3000/ (without the C++ API)
```

| Command | What it does |
| ------- | ------------ |
| `npm run sync-docs` | Copy `python/README.md` and the printf target tutorial into `docs/generated/` |
| `npm run api` | Generate the C++ API reference into `static/api/` |
| `npm run build` | sync-docs + api + production build into `build/` |
| `npm run build:site` | sync-docs + production build, without Doxygen |
| `npm run serve` | Serve `build/` locally |

Broken links fail the build.

## Docker

Build from the repository root, since Doxygen reads the module headers:

```bash
docker build -f docs-site/Dockerfile -t docc-docs .
docker run --rm -p 8088:8080 docc-docs    # http://localhost:8088/
```

## Search indexing

`DOCS_NOINDEX` (default `true`) keeps search engines out: every page gets `noindex`, `robots.txt` disallows everything, and no sitemap is generated. Build with `DOCS_NOINDEX=false` once the site is served on docc.daisytuner.com.

## Deployment

The site runs on Cloud Run as service `docc-docs` in project `daisy-367210` (`europe-west1`).

- **CI:** `.github/workflows/docs.yml` builds and smoke-tests the image on pull requests, and deploys on pushes to `main` or manual runs on `main`. It needs the `GOOGLE_APPLICATION_CREDENTIALS` secret. The repository variable `DOCS_NOINDEX` controls indexing.
- **Manual:** `docs-site/scripts/deploy-cloudrun.sh` builds, pushes, and deploys from your machine using your `gcloud` login.

Neither path changes the service's IAM policy; public access (`allUsers` as `roles/run.invoker`) was granted once by a project owner.
